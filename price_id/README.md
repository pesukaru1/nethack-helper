# price_id — ценовая идентификация предметов NetHack

Скрипт для быстрой идентификации неопознанных **свитков** и **зелий** по цене
(таблицы «NetHack 3.6.0 и позднее» из `price_id.html`): по цене находит
возможные предметы и предлагает **псевдоним для ввода в игре**.

Работает на Mac/PC/Android (Termux): только стандартная библиотека Python 3,
никаких pip-пакетов.

## Файлы

| Файл                    | Что это                                                        |
|-------------------------|----------------------------------------------------------------|
| `price_id.py`           | скрипт                                                         |
| `price_id_data.json`    | данные из `price_id.html` (собирается автоматически)           |
| `price_id_abbr.json`    | сокращения предметов для псевдонимов (можно править вручную)   |
| `РАЗБОР.md`             | построчный разбор кода — как всё устроено внутри               |
| `sessions.json`         | сессии (создаётся при первом использовании)                    |
| `sessions/<имя>/*.csv`  | CSV сессии: `appearance;alias;function` по ходу игры           |

## Быстрый старт

```bash
python3 price_id.py            # интерактивный режим
python3 price_id.py --help
python3 price_id.py --selftest # самопроверка (примеры из сценариев)
```

Первый запуск сам попросит создать сессию (имя, герой, роль, харизма).
Примеры сессий: Android, Mac, PC, Steam.

### Сценарий из игры (продажа)

Бросили свиток на пол, торговец предлагает 30 монет:

```
[Mac] > s 30 scroll GHOTI
Продажа 30 — свитков (совпадений: 4):
  1. blank paper (unlabeled scroll) — 60 zm
  2. enchant weapon — 60 zm
  3. enchant armor — 80 zm  [скидка]
  4. remove curse — 80 zm  [скидка]
Псевдоним: bp/ew/ea/rc
Запись: GHOTI → bp/ew/ea/rc (записан) [sessions/Mac/scrolls.csv]
```

Копируем `bp/ew/ea/rc` в игру как имя предмета. Запись о метке сразу
сохраняется в CSV сессии.

### Покупка

При покупке торговец называет цену с учётом харизмы сессии; при необходимости
укажите цену и вид, метку — когда предмет окажется у вас:

```
[Mac] > b 300 potion
Покупка 300 (Cha 7) — зелий (совпадений: 10):
  ...
Псевдоним: s75_1  (sell в категории: 75/100, взят min)
```

## Команды

```
s <цена> [sc|po] [метка]   продажа (магазин платит за ваш предмет)
b <цена> [sc|po] [метка]   покупка (магазин просит)
n <метка> [псевдоним]      вручную переименовать/посмотреть запись
i <метка> [предмет]        отметить распознанным (i GHOTI ew; i GHOTI — показать)
d <метка>                  удалить запись предмета
l [неоп|расп|все]          список предметов сессии
sess [use|new|rm|set]      сессии и их параметры
help / q                   справка / выход
```

Одноразовый режим: `python3 price_id.py s 30 scroll GHOTI` и т.п.
(добавьте `--session Mac`, если сессия не последняя).

## Правила псевдонимов

* **≤ 5 вариантов** — сокращённые имена через `/`: `bp/ew/ea/rc`,
  `amn/crmon/eart/tam` (сокращения — в `price_id_abbr.json`, у каждого
  предмета список стилей).
* Если у двух предметов сессии совпадает набор вариантов (одинаковая цена),
  второй получит следующий стиль: `bp/ew/ea/rc` → `blank/enchw/enchar/remcur`
  → `bpap/enweap/earm/rcur` (далее — с суффиксом `-2`, `-3`…), чтобы предметы
  различались в игре.
* **≥ 6 вариантов** — `s<цена>_<n>`, где для покупки берётся цена из колонки
  Selling price (если у категории их несколько — минимальная, это видно в выводе).
  Нумерация `n` продолжается по уже выданным псевдонимам той же категории.
* **Наценки учитываются автоматически**: при покупке проверяются все три числа
  колонки харизмы (обычная цена; +1/3 за неопознанность или «сучка»; обе
  надбавки), при продаже — оба числа (обычная и «скидка» магазина).
* Если продажа не нашла совпадений, но цена похожа на «сучковую»
  (dunce cap / видимая рубашка / Tourist < 15 lvl) — скрипт подскажет варианты.

## Распознанные предметы

Отмеченные распознанными типы (`i GHOTI ew`) исключаются из всех новых
списков: если GHOTI оказался `enchant weapon`, то у другой метки с ценой 30
останется псевдоним `bp/ea/rc`. Соответствие метка→функция сразу попадает
в CSV сессии.

## Сессии и CSV

```bash
python3 price_id.py sess                       # список
python3 price_id.py sess new Android           # создать (спросит героя/роль/Cha)
python3 price_id.py sess use Mac               # переключиться
python3 price_id.py sess set cha 16            # изменить характеристику
python3 price_id.py sess set level 5           # любые доп. характеристики
python3 price_id.py sess rm PC                 # удалить
```

CSV лежат в `sessions/<имя>/` и обновляются при каждом изменении:

```
appearance;alias;function
GHOTI;bp/ew/ea/rc;scroll of enchant weapon
fizzy;s50_1;
```

## Обновление таблиц данных

Скрипт сам строит `price_id_data.json` из `price_id.html` (ищет его рядом
с собой или на уровень выше). После правки HTML:

```bash
python3 price_id.py --rebuild [--html путь/к/price_id.html]
```

## Примечания

* Пулы меток/цветов (для подсказок при опечатках) встроены. В `scrolls.md`
  31 метка из 41 возможных в 3.6.x (нет, например, GHOTI и HAPAX LEGOMENON,
  которые встречаются в примерах) — скрипт использует полный пул; ввод любой
  другой метки не блокируется.
* `blank paper` показывается в игре как «unlabeled scroll»; в списках кандидатов
  он остаётся (как в сценарии ТЗ) — учитывайте, что к свиткам с меткой он
  технически не подходит.
* Цена за стопку (не за один предмет) не поддерживается — бросайте по одному.
* Подсказки по опечаткам не мешают: метка записывается как введена, удалить
  или переименовать — `d` / `n`.
